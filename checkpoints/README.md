# Checkpoints

This directory contains only the model weights used by the paper. The files are
PyTorch `state_dict` objects and do not contain optimizer state or training data.

- `n87_paper_models/`: the thirteen N87 models. Seven are the controlled
  comparison and the structural ablation; the other six complete the joint
  ablation of time-step normalization and limiting functions, whose folders
  carry a `_max_step` or `_rms_slope` suffix because that table reports both
  normalization schemes for each limiter.
- `ten_material_rategru/`: one selected RateGRU checkpoint for each of the ten
  materials in the cross-material table.
- `manifest.json`: model keys, selected hyperparameters, SHA-256 checksums, and
  every error the manuscript reports for that checkpoint. `null` marks a metric
  the manuscript prints as N/A.

Each checkpoint folder also contains a `run_config.json` with the full checked
configuration in the same schema a locally trained run writes, with the raw
input directory left empty because no data ships here. It is generated by
`scripts/write_checkpoint_run_configs.py` from `paper_experiments.py`; re-run
that script after changing the selected configurations.

`n87_paper_models/rategru/model.pth` and
`ten_material_rategru/N87/model.pth` are intentionally byte-identical. The
duplicate lets each experiment collection remain self-contained.

Load a checkpoint with:

```python
import torch

from models import SoftplusRateExpCapGRU

model = SoftplusRateExpCapGRU()
state = torch.load("checkpoints/n87_paper_models/rategru/model.pth",
                   map_location="cpu", weights_only=True)
model.load_state_dict(state, strict=True)
model.eval()
```
